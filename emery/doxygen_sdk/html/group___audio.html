◆ audio_context_get_cached_status()

AudioContextAvailability audio_context_get_cached_status ( AudioContextStatus * status_out)

Gets the most recent cached Audio Context status.

This function does not contact the phone. Before a status response has been received, the cached availability is AudioContextAvailabilityUnsupportedPhone.

Parameters
status_outOptional destination for the cached status.
Returns
The cached availability value.

◆ audio_context_request_enable()

bool audio_context_request_enable ( void )

Asks the system to show the background audio enable flow.

Apps cannot enable background audio directly. This function only requests that the phone show the user an appropriate flow.

Returns
True if the request was sent, false otherwise. This is not the result of the user prompt.

◆ audio_context_request_permission()

bool audio_context_request_permission ( AudioContextPermission permissions)

Asks the system to show the Audio Context permission flow.

The app must declare the matching capabilities in package.json. This function does not grant permissions directly and does not report the final prompt result. Request status or transcript data afterwards to observe the current permission state.

Parameters
permissionsBitmask of AudioContextPermission values.
Returns
True if the request was sent, false otherwise. This is not the result of the user prompt.

Typedef Documentation

◆ AudioContextStatusCallback

typedef void(* AudioContextStatusCallback) (AudioContextAvailability result, const AudioContextStatus *status, void *context)

Callback for asynchronous Audio Context status requests.

If result is not AudioContextAvailabilityAvailable, status may be NULL. The callback runs on the app event loop.

◆ AudioContextTranscriptCallback

typedef void(* AudioContextTranscriptCallback) (AudioContextAvailability result, const AudioContextTranscript *transcript, void *context)

Callback for transcript query and subscription results.

If result is not AudioContextAvailabilityAvailable, transcript may be NULL. The transcript pointer and transcript->text are valid only for the duration of the callback. Copy the text before returning if it is needed later.

enum AudioContextAvailability

Availability or failure reason for Audio Context requests.

Enumerator
AudioContextAvailabilityAvailable 

Audio Context is available.

AudioContextAvailabilityUnsupportedWatch 

The connected watch or firmware does not support Audio Context.

AudioContextAvailabilityUnsupportedPhone 

The connected phone app does not support Audio Context.

AudioContextAvailabilityDisabledByUser 

The user has disabled system background audio.

AudioContextAvailabilityPermissionDenied 

The user has not granted this app the requested audio access.

AudioContextAvailabilityCapabilityNotDeclared 

The app did not declare the required capability in package.json.

AudioContextAvailabilityTranscriptionUnavailable 

Transcription is not available for the requested audio data.

AudioContextAvailabilityNoData 

No transcript data is available for the requested time window.

AudioContextAvailabilityError 

An unexpected error occurred.
